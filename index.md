# Privacy Policy – Personal WHOOP Integration

**Last updated:** August 2026

This is a private, personal developer application created by Julian Kleinz.  
It is not a commercial product and is not available to the public.

## Purpose
The application connects to the WHOOP API solely so that I can access and process my own WHOOP data (recovery, sleep, strain, workouts, body measurements, etc.) for personal use in a private AI assistant.

## Data accessed
Only data belonging to my own WHOOP account, obtained via the official WHOOP API after I authorize the application.

## How the data is used
The data is used exclusively for my personal health and nutrition planning.  
It is not used for any commercial purpose, advertising, or automated decision-making affecting others.

## Data sharing
No data is sold, shared, or transferred to any third parties.

## Data storage
Data is stored only on my personal devices / private server under my control.  
Access tokens and refresh tokens are stored securely and are never exposed publicly.
